# J.A.R.V.I.S. Holographic Interface

A futuristic AR/3D interactive interface inspired by Iron Man's HUD. Control a holographic globe, data panels, and sci-fi sound effects via webcam and gesture recognition — perfect for creative showcases, science demos, or human-computer interaction prototypes.

> Language: Chinese (UI and copy) | Tech Stack: React + Vite + Three.js + MediaPipe
> All code in this project was generated by Gemini 3 Pro and is for learning and demonstration purposes only. If you run into issues, feel free to ask an AI for help~

## Highlights

- **Holographic Globe**: A rotatable, tiltable glowing Earth with wireframe and cloud layer overlays (`components/HolographicEarth.tsx`)
- **Tactical Terrain**: Switch to a tactical terrain view with target marker animations via a left-hand "spread" gesture
- **Gesture Control**:
  - Right-hand horizontal movement controls rotation; vertical movement controls tilt (`components/VideoFeed.tsx:94-103`)
  - Right-hand pinch toggles the intel panel on/off (`components/HUDOverlay.tsx:266-278`)
  - Left-hand spread degree controls zoom/expansion (`components/VideoFeed.tsx:82-88`)
- **Camera & Skeleton Rendering**: Canvas-rendered dual-hand skeletons with dynamic fingertip/palm indicators (`components/HUDOverlay.tsx`)
- **Boot Sequence & Voice**: System boot animation with TTS voice prompts (`components/JarvisIntro.tsx`, `services/soundService.ts`)
- **Sci-Fi HUD**: Multi-layered overlay — trails, scanlines, gauges, data source lists (`components/HUDOverlay.tsx`)

## Tech Stack

- `React 18`, `TypeScript`, `Vite 6`
- `three`, `@react-three/fiber`, `@react-three/drei`, `@react-three/postprocessing`

## Quick Start

## Gesture Interaction Guide

- **Right-hand Rotate/Tilt**: Move your right hand horizontally across the frame to spin the globe, and vertically to control tilt (`components/VideoFeed.tsx:94-103`, `components/HolographicEarth.tsx:320-347`)
- **Right-hand Pinch**: Bring thumb and index finger close together to trigger a pinch, toggling the intel panel on/off (`components/HUDOverlay.tsx:266-278`)
- **Left-hand Spread**: The spread degree maps to an expansion factor, controlling zoom and triggering tactical terrain mode beyond a threshold (`components/VideoFeed.tsx:82-88`, `components/HolographicEarth.tsx:349-391`)

## Permissions & Privacy

- This project requires camera access for gesture recognition; the permission declaration is at `metadata.json:4-6`
- Camera footage is processed entirely in the local browser and is never uploaded to any server
- Audio playback and speech synthesis may require a user interaction to activate (browser autoplay policy)

## Browser Compatibility & Notes

- On first visit, video/audio may require a click to activate due to autoplay policies (`components/VideoFeed.tsx:31-43`, `services/soundService.ts:6-16`)
- If MediaPipe's primary CDN fails to load, the code automatically falls back to a secondary CDN (`services/mediapipeService.ts:17-28`)
- For best gesture recognition results, use in a well-lit environment with a clean background

## FAQ

- **Camera not working**: Check browser permission settings, or access the page over HTTPS
- **No sound**: Perform at least one click to enable `AudioContext` (browser autoplay restriction)
- **Low performance**: Lower the resolution or run on a high-performance device / desktop browser; close other GPU-intensive tabs
