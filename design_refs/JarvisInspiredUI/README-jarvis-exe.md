## Setup: Auto-Open on Unlock (Windows)

1. Press `Win + R`, type `shell:startup`, and press Enter.
2. Copy `J.A.R.V.I.S.exe` from the `dist/win-unpacked` folder to the Startup folder.
3. JARVIS will auto-launch every time you log in or unlock your computer.

## Usage Instructions

- Double-click `J.A.R.V.I.S.exe` to launch the HUD.
- The app runs in portable mode, no installation required.
- All features are accessible from the main interface.
